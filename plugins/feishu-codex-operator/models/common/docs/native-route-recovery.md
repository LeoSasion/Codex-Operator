# 恢复官方默认路由

创建持久全局路由时应先准备桌面的 **恢复官方默认路由** 快捷方式。
`scripts/install-native-recovery-shortcut.ps1` 把两个恢复文件保存到所选项目的
`.codex/operator-native-recovery`，核验桌面链接并记录所有权。准备过程不执行恢复或修改路由。
重复设置保留未变的文件；链接丢失时补建；用户修改或同名未知链接会停止设置。
原件和写入意图先保存，不能用缺失的记录收养已有文件。

新版 `init --codex-config <实际全局配置>` 在创建状态前准备入口；新版 `activate`
对当前用户默认 home 的全局配置在健康检查前自动准备入口，失败则不激活。
普通 `init` 未指定配置只初始化私有状态；隔离配置不会改真实桌面。
非默认 home 由设置工作流显式准备并核对目标，不能据此宣称当前快捷方式能恢复所有 home。
模型适配 skill 已将此步骤列为用户路由设置的一部分，授权范围内不再单独询问。

双击插件 `scripts` 目录中的 **恢复官方默认路由.cmd**。看到完成提示后，
自行彻底退出 Codex，再从官方 Codex 入口打开，选择官方模型。
窗口会保留结果和恢复记录位置，无需填写地址、令牌或运行代码。
先结束正在进行的工作；脚本本身不会关闭任务、结束进程或重发失败请求。

这个入口使用 Windows 自带的 PowerShell 5.1，也支持 PowerShell 7。
无需安装 Python、启动路由、打开网页登录或找到旧路由的状态目录。
批处理只给本次 PowerShell 子进程指定执行策略，不改系统的永久策略。
运行时默认使用当前用户的 Codex home，也尊重显式的 `CODEX_HOME`。
安装器同时复制脚本和批处理到 runtime；插件源码中的入口可以直接运行。

## 实际处理范围

- 只移除文件开头、格式与本插件一致的三行全局路由块。接受 UTF-8 BOM、LF/CRLF，
  保留前置注释及其余配置的原始字节。已经注释掉的路由块不再改写。
- 无需 `codex-entry.json` 或当前 token。这是所有者主动停用已识别路由，
  不是假定缺失的安装记录存在，也不声称恢复整份原始配置。
- 写入独立的 `operator-native-route-only` 保护标记。新版全局激活助手会在网络访问前
  拒绝重新激活；新版拓展入口遇到标记直接打开原生应用。普通升级保留标记。
  明确重新评审并选择全局路由之前，不应删除它。独立的第三方 provider 配置不受此标记影响。
- 对本项目存在且构建摘要一致的拓展启动器，仅将启动配置的 `mode` 改为 `native`，
  其余字段保留。这也能阻止仍使用旧入口代码的已核验启动器执行旧工作流。
  若构建记录缺失或内容被修改，保留它并报告需要核对；不会因此阻止移除明确的全局路由。
- 不修改官方快捷方式、应用本体、登录资料、历史、默认模型、模型权重、目录缓存、
  工具审批或飞书状态。不停止后台服务，不修改路由令牌，不删除原路由登记。

它不是清空 Codex 设置的“恢复出厂”按钮。其他供应商、配置档案、自定义路由、
无法识别的标记、链接路径和并发修改会停止相应操作。配置检查是保守的文本识别，
不是完整 TOML 解释器；即使只有未选用的复杂配置档案，也可能需要维护者核对。
发现 `OPENAI_BASE_URL` 环境覆盖或未核验的拓展入口时，会明确报告尚需核对，
不会将局部处理宣称为全部恢复。旧版、被修改或其他项目的启动程序不能据此视作已受保护。

## 备份和中断

写入前在 Codex home 的 `operator-route-recovery` 内建立唯一的私有目录，
只允许当前用户和 SYSTEM 访问；保存精确原件、目标路径和前后摘要。
每个文件独立替换，写入前复查当前摘要，写入后核对结果。
多个文件不属于一次原子事务；中途失败会列出已完成项目，并保留意图记录和备份，
不会自动回放、覆盖后续修改或恢复旧的故障路由。重复运行会收敛，
已经完成的操作不重复写入，也不覆盖前次备份。备份可能包含私人配置，不应上传或发布。

通常无需手动恢复整份备份。维护者可先比较其中的 `*.before` 和 `intent.json`，
仅处理发生冲突的字段；不要直接把旧路由地址重新放回全局配置。
现有运行中的 Codex 可能仍使用已加载的连接和任务模型，所以应在方便时自行退出再打开。
脚本不以磁盘修改证明 UI 已刷新或实际模型请求已经成功。

维护者只读检查：

```powershell
.\scripts\restore-codex-official-route.ps1 -Json
```

命令入口为 `operator recover-native`，默认预览；加 `-Apply` 才写入。
独立脚本另支持显式 `-CodexHome` 和 `-ProjectRoot`，测试必须使用隔离目录。
不要以 `status`、`doctor` 或 `readiness` 触发恢复。
