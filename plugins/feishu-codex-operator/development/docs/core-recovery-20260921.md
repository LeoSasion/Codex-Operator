# 核心能力验证摘要

本文件仅记录可公开的验收范围。运行日志、账号资料、进程记录、任务身份和维护原件留在本地。
完整预览版验证说明见 [发布审计](release-audit.md)。

## 已验证范围

- Channels：已有飞书绑定的接收、固定 Beeper 转交、原生任务续接、Final Callback 回传，以及 `/model` 对当前绑定任务的官方模型选择。控制消息不调用模型。
- Web：独立原生 CLI 的文字、搜索、同会话续接、读改测样例及取消后新请求复用。后来增加了 Desktop 普通输入三轮和原生停止后任务工具新请求的实证，准确边界统一见[发布审计](release-audit.md)；两组证据不合并成普通输入框整条停止链路通过。
- Local：已选模型的隔离 CLI 读写样例。单个模型通过不代表全部模型或 Desktop 工具兼容。
- 生命周期：保存登录与固定连接、保守的不重放规则、官方直连保护、安装与卸载边界。

## alpha.137 审查修复

独立 Web 服务在卸载前单独检查；首次建任务先检查新鲜额度状态；官方恢复保护不妨碍只读状态和准确清理；卸载区分已知源码与安装副本的路由身份；安装清单包含必需的 Web tunnel 模块。

最终 Python 回归 859 项，其中 849 项通过、10 项既有选择性跳过；Node 82 项通过。安装后的 Web 模块通过隔离导入检查。历史失败保留，修正后的结果不会覆盖原始失败。

## 仍需单独验收

新用户使用另一个授权账号首次自动建任务、外部模型的原生主窗口菜单与同任务切换、旧安装的完整迁移，以及具体 API/本地模型的端点兼容。预览版保持原生官方直连，不把隔离测试当作全局路由就绪。
